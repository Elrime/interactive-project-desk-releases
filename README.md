# Interactive Project Desk — релизы

Публичный канал установщиков и автообновлений. Сорцы: https://github.com/Elrime/interactive_project_desk (приватный).

- `latest.json` — endpoint updater-плагина
- инсталляторы Windows/macOS/Linux, подписанные ключом updater

Установка: страница Releases → последний релиз. Windows: также `winget install Elrime.InteractiveProjectDesk` (после мержа манифестов).
